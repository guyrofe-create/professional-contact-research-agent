# Professional Contact Research Agent

כלי לאיסוף שיטתי של כתובות מייל מקצועיות ופומביות בלבד עבור אנשי מקצוע וארגונים בתחום בריאות האישה, הריון, לידה ופוריות.

## קטגוריות
המאגר כולל בין היתר רופאי נשים ופוריות, רופאי משפחה, מנהלי מרפאות,
מרכזי בריאות האישה, מרפאות קהילה, יחידות IVF, מיילדות, דולות,
יועצות הנקה, פיזיותרפיסטיות רצפת אגן ואנשי מקצוע נוספים סביב הריון ולידה.

## קלט
CSV או XLSX עם לפחות שתי עמודות:

```csv
name,category
ישראל ישראלי,gynecologist
שרה כהן,doula
```

ניתן להוסיף עמודות אחרות. הן אינן חובה.

## התקנה והרצה

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python agent.py targets.csv --out output --resume
```

`--resume` גורם לכלי להמשיך מה-checkpoint ולא לבצע שוב אנשים שכבר נבדקו.

## פלט
* `output/audit.xlsx` - כל יעד שנבדק, כולל מי שלא נמצא עבורו מייל.
* `output/contacts.xlsx` - כל הכתובות המאומתות שנמצאו, כולל כמה כתובות ליעד כאשר יש יותר מכתובת מקצועית מתאימה, ולאחר הסרת כפילויות לפי מייל.
* `output/checkpoint.jsonl` - checkpoint לאחר כל אדם.
* `output/summary.json` - מספר יעדים, נמצאו, לא נמצאו ומיילים ייחודיים.

## כללי אימות
הכלי אינו מייצר או מנחש כתובות מייל. כתובת נשמרת רק אם היא הופיעה בפועל בדף ציבורי שנפתח במהלך המחקר. כתובות דוגמה, תיבות מערכת שאינן מתאימות לפנייה, מאגרי לידים צד שלישי וכתובות שאינן משויכות בבירור ליעד נפסלים. נשמר גם `source_url` שממנו הכתובת נשלפה. `confidence` הוא ציון התאמה בין האדם, הדף והמייל ואינו הוכחה לזהות בפני עצמו.

## תהליך החיפוש
לכל יעד מתבצעות מספר שאילתות חיפוש. הכלי פותח תוצאות רלוונטיות, ממשיך עד שתי שכבות לעמודי contact/about/team/profile, עוקב אחרי קישור לאתר רשמי מתוך אינדקס מקצועי, ומחלץ גם כתובות מוסוות וכתובות המוגנות באמצעות Cloudflare. כך ניתן למצוא מייל גם כאשר לאדם אין אתר אישי, למשל באתר מרפאה, בית חולים, קופת חולים, מוסד אקדמי או גוף מקצועי. כתובת מחלקתית מתקבלת רק כשיש קשר מתועד לרופא, למרפאה או ליחידה הרלוונטית.

## הערה חשובה
יש להשתמש רק במידע מקצועי שפורסם לציבור ובכפוף לתנאי השימוש, robots.txt והדין החל. אין להשתמש בכלי לעקיפת login, CAPTCHA, הגנות אתר או מגבלות גישה.
